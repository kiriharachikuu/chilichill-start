厚嘴唇空间站

ChiliChill Fan Spaceport —— 一张通往同好宇宙的复古登船票

设计概念从「通用深色星空」升级为「深空港 × 复古登船票」：墨蓝深空仍是底色，但用衬线星体标题、等宽航行日志、票根撕口与邮戳章，把「导航站」做出纸质票根的仪式感。粉丝不是在浏览一个目录，而是在领取一张通往同好舱段的船票。

00

设计概念与差异化

记忆点（只保留一个，做深）：「撕口票根 + 邮戳章」。导航项像一张船票，两侧半圆撕口、中间虚线存根；审核动作像在船票上盖戳。配合 Fraunces 衬线（星图海报感）与 Space Mono 等宽字（航行编号感），彻底避开「Inter + 紫蓝渐变卡片」的通用 AI 审美。

氛围

墨蓝深空、极淡噪点颗粒、缓慢漂移的极光与轨道环。亮处只留给信号色，大面积保留深色呼吸感。

质感

玻璃面板仅用于弹层与悬浮区；主内容用「深墨抬升面 + 细描边」，票根用暖色半透明纸质层，形成冷暖对比。

叙事

群 = 群舱，网站 = 星港站点，投稿 = 发送信号，审核 = 校准 / 盖戳。全站文案统一太空港隐喻。

01

05

交互动效规范

动效服务于「信号 / 航行」叙事：入场像接收信号（上浮淡入），悬停像脱离重力（轻微上浮），成功像盖戳（弹性缩放）。默认尊重 prefers-reduced-motion。

页面入场 · Signal In

区块自下而上 26px 淡入，依次 stagger 0.08 / 0.18 / 0.3s。

持续氛围 · Ambient

星点闪烁 3s、漂浮 6s、极光漂移 18s、轨道环 20–48s 匀速旋转。

twinkle 3s · float 6s · aurora 18s orbit spin 20s/32s/48s linear infinite
呼吸中

时长档位

微交互 .16s · 常规 .28s · 强调 .5s · 叙事入场 .9s。超过 1s 的动效仅用于氛围背景。

抽屉 / 弹层

遮罩淡入 .28s；面板自右侧 40px 滑入并淡入，ease-out；关闭反向，时长 .28s。

列表更新

筛选 / 分页切换时内容区淡入 .3s；加载用信号脉冲骨架屏，不使用旋转菊花。

06

响应式适配规则

移动优先，四档断点。桌面筛选侧栏在平板收起为横向筛选条，在手机收纳进折叠面板；卡片栅格逐级降列；触控目标不小于 40×40px。

断点区间栅格导航 / 筛选间距

sm 大手机/小平板640 – 767px 卡片 2 列；统计 3 列 汉堡菜单；筛选横向滚动条 区块 60px；页边 24px
md 平板768 – 1023px 卡片 2 列；大区 3 列 顶部完整导航；筛选横条 区块 64px；页边 32px
lg 桌面1024px+ 卡片 3 列；大区 5 列 完整导航 + 左侧筛选栏 区块 80px；内容 1120px

字号缩放

Hero 使用 clamp(40px,7vw,76px) 流式缩放；正文固定 15px，不在移动端缩小正文字号。

图片 / 封面

站点封面固定比例 16:7；二维码 1:1；使用 srcset 或容器自适应，禁止横向溢出。

触控

所有可点元素 ≥40px 高；手机端按钮之间留 8px 以上，复制群号改为整行按钮更易点。

07

无障碍与实现约束

视觉创新不以牺牲可用性为代价；以下规则在像素级实现阶段逐条落地。

对比度

正文 / 主文字对底色 ≥ 4.5:1；信号色仅用于大字、图标与边框时可用 3:1 档位。

焦点可见

键盘焦点统一为 3px 琥珀色光环（rgba(245,166,59,.25)），不使用浏览器默认描边但绝不移除焦点。

减弱动效

prefers-reduced-motion 时关闭轨道 / 漂浮 / 入场动画，仅保留必要的透明度反馈。

语义与外链

卡片用 article，导航用 nav；站点外链 target="_blank" 必带 rel="noopener noreferrer"；图标按钮带 aria-label。

令牌落地

全部颜色 / 圆角 / 阴影 / 动效以 CSS 变量 + Tailwind theme.extend 双写一致，禁止组件内硬编码色值。

还原标准

以本规范为唯一视觉真值；实现后在 375 / 768 / 1280 三宽度截图比对，间距偏差不超过 2px。
