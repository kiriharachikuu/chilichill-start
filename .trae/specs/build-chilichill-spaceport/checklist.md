# Checklist

- [x] `npm install` + `npm run dev` 可同时启动前后端，`/api/health` 返回 200
- [x] Prisma 建表成功，种子数据包含城市大区映射、关键词规则、示例群/站点/标签与管理员账号
- [x] 注册/登录/登出可用，密码以 bcrypt 存储，JWT 存于 httpOnly Cookie
- [x] 普通用户访问 `/api/admin/*` 返回 403，`/admin` 页面阻止进入
- [x] 投稿群时先单选群类型；仅「地区粉丝群」展示城市勾选选择框，线上功能群与其他类型不展示城市框
- [x] 地区群勾选城市后自动得出大区（如广州 → 华南），与群名是否含城市名/「粉丝群」字样无关
- [x] 线上功能群必须选择功能标签，关键词规则仅作标签推荐，不决定大区
- [x] 「其他」类型投稿大区标记待定，管理员未指定至少一个自定义标签时无法通过
- [x] 新建投稿在审核通过前不出现在公开列表，通过后可立即看到
- [x] 修改已发布内容会生成 UPDATE 投稿，审核通过前线上内容保持不变
- [x] 驳回必须填写原因，投稿人可在「我的投稿」看到原因并编辑重新提交
- [x] 审核通过使用事务写入，重复审核/并发审核不会产生重复内容
- [x] 上传接口限制 png/jpg/jpeg/webp 且 ≤5MB，非法文件被拒且不落盘
- [x] 配置 COS 环境变量后切换为 COS 存储；未配置时使用本地存储且 URL 可访问
- [x] 群导航支持群类型、大区、标签、关键词筛选与分页，群号可复制
- [x] 网站导航支持标签筛选、关键词搜索，外链使用 `noopener noreferrer`
- [x] 后台支持标签 CRUD、城市大区映射维护、关键词规则维护，改动即时反映到前端筛选器
- [x] 投稿/审核实体通过注册表抽象，`EXTENDING.md` 说明画廊、音乐厅接入步骤且与代码一致
- [x] 375px 移动端无横向溢出，筛选与表单可正常操作
- [x] `npm run build` 与 TypeScript 类型检查通过
